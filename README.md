# 🎓 Máster Frontend - Lemoncode

Este repositorio recopila las **prácticas, ejercicios y proyectos** realizados durante el **Máster en Frontend Online de [Lemoncode](https://lemoncode.net/)**.  

El objetivo es documentar el progreso, aplicar las tecnologías vistas en el programa y crear un portfolio de proyectos frontend.

---



## 📂 Estructura del repositorio

Cada carpeta corresponde a un **módulo** o **bloque temático** del máster:
- /01-html-css
- /02-javascript
- /03-bundling
- /04-frameworks
- /05-testing
- /06-rest-api
- /07-cloud
- /08-mobile


## 🧑‍💻 Tecnologías y herramientas

A lo largo del máster se trabajan diferentes tecnologías y buenas prácticas, entre ellas:

- **Layout:** Building layouts with HMTL / CSS 3, SASS, TailWind...  
- **Lenguajes:** Javascript ES5, ES6, Typescript.
- **Bundling:** Webpack / Vite.
- **Frameworks:** React, Vuejs, Angular, SolidJS, Svelte, Astro.
- **Testing:** Jest, Vitest React Testing Library, Cypress, Playwright.
- **Rest-api:** fetch, axios, graphql.
- **Cloud:** render, amazon, azure + docker + github actions.
- **Mobile:** PWA, React Native.



---

## 🎯 Objetivos del repositorio

- Documentar el aprendizaje adquirido en el máster.  
- Crear un histórico de proyectos y ejercicios.  
- Poner en práctica buenas prácticas de desarrollo frontend.
